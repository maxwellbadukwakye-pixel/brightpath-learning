# Maxwell Kwakye Learning Code

A responsive static learning website for Web Development, Python, and Microsoft Excel.

## Files
- `index.html` — website content and lesson links
- `styles.css` — responsive styling
- `script.js` — mobile navigation, course search, and a sample quiz
- `assets/logo.svg` — custom MK logo
- `assets/maxwell-learning-hero.png` — hero illustration

## Preview on your computer
Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account at https://github.com/
2. Create a **public** repository named `maxwell-kwakye-learning-code`.
3. Open the repository, choose **Add file → Upload files**, and upload the contents of this folder (not just the ZIP file).
4. Commit the uploaded files to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
7. Wait for the deployment to finish. Your public address will look like `https://YOUR-USERNAME.github.io/maxwell-kwakye-learning-code/`.

## Publish free with Vercel
1. Extract the ZIP on your computer.
2. Sign in at https://vercel.com/ and import the GitHub repository, or use Vercel's supported deployment workflow.
3. This is a static HTML/CSS/JS site; no build command is needed. The output/root directory is the project root.
4. Deploy and use the public `*.vercel.app` URL Vercel provides.

## Before launch
- Replace `hello@example.com` in `index.html` with your own email address.
- The logo and hero illustration are included locally, so they load with the website.
- The included quiz is a small demonstration; add more questions as desired.
- This package is a website project, not a deployment already hosted online. You must complete one of the hosting workflows above to receive a public URL.
